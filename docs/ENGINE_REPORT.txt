Notes
- Simulated EPA Net3 city with harsh noise; seeded; each row of the table = 40 fresh cities.
- 40-case rows swing about +/-7 % between samples (the earlier stage-6 run showed 78-82 % found within 3
  visits; with 120 cases per size it is 58-75 %). Quote the larger run.
- "Skeptic correct" = the final leak / not-leak call is right. no_alarm means the event never even raised an alarm.
- Search = locate -> next-best acoustic survey (85 % hit, 5 % false "yes", 5 % inconclusive, which costs a
  visit and is repeated) -> dig only on "yes" -> soft elimination.
- Calibration: the top area's relative likelihood is LOWER than how often the leak is really there
  (e.g. 34 % said vs 55 % real at 20 L/s). The scores are conservative and are not calibrated
  probabilities - the dashboard labels them "relative likelihood".
- Auditor: when not "correct" the verdict is almost always INCONCLUSIVE (keep watching), not wrong.
  In the "partly" rows the ~5 % FIXED verdicts are cases where the second simulated leak sits at a
  low-pressure node and leaks almost nothing (measured remaining excess ~0 L/s) - physically correct.
- Agent-level (end-to-end) results: docs/EVAL.md. Ablation: docs/ABLATION.md.
